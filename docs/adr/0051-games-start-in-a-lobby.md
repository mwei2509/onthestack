# Games start in a lobby, where joining adds a seat

Status: Accepted (decided with Melissa, 2026-11-23, in the planning session for #42).

Amended by ADR 0064 (the Deck is optional until the Deck library exists) and ADR 0080 (a seat needs a Deck). Amended by ADR 0092 (anyone at the table can end a game).

Creating a game makes an empty lobby, not a game with seats filled in by one person. Each device that opens the game's link joins with a name and a saved Deck (or imports one there), and that adds a seat. The person who created the game joins the same way.

- **Seating order** is the order people join, and anyone can drag the seats to match where people actually sit, clockwise. Anyone can also rename a seat, change its Deck or remove it. It's a trusted table.
- **Starting:** anyone can press Start game, which asks who goes first. The table rolls dice for that, and turns then run clockwise from the winner, so nobody re-orders the seats after the roll. Start creates the engine's game state from the seats.
- **After Start**, a device can only take an existing seat or watch. Adding a player mid-game would change the turn order, so it isn't supported.

Seats for players without a phone, added by someone else, are left out of the first build.

## Consequences

- The Game Durable Object has two phases, lobby and game, and the engine's state exists only from Start.
- Player IDs are generated by the server, so two players with the same name never collide. Names are only for display.
