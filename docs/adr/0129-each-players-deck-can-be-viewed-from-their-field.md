# Each player's Deck can be viewed from their field

Status: Accepted (decided with Melissa, 2026-11-24, in the session planning #170)

Each player's battlefield screen, and their seat card on a Shared screen, has a **Deck** button. It opens the Deck viewer (ADR 0084), read-only, on the Deck version that seat is playing (ADR 0119), so a Deck edited since Start shows what's actually in the game. Anyone at the table can look at any player's Deck. It shows the decklist only, never the order of a library or what's in a hand (ADR 0126).

Considered: only your own Deck, which hides what the library already makes public; and tapping the commander instead of a button, which is harder to find.
