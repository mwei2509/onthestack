# Games have readable codes

Status: Accepted (decided with Melissa, 2026-11-23, in the planning session for #42).

Amended by ADR 0095 (six-digit join codes beside the game code).

A game's link is `onthestack.gg/g/<code>`, with a code like `KITE-MOSS-42`: two words and two digits, generated by the server when the game is created (`POST /api/games`). It's easy to read across the table and type on another phone, and it doubles as the room code that ADR 0002 mentions.

Two words plus digits give millions of combinations, so a stranger can't stumble into a live game by guessing. A single word and two digits would be guessable. The code is the only way into a game: there are no accounts, and anyone with the code is trusted like someone at the table.

## Consequences

- Creating a game never happens over a game's socket, so opening an empty code can't overwrite a game.
- QR codes in M2 encode the same link.
