# "Go back" waits for take-backs

Status: Accepted (decided with Melissa, 2026-11-24, in the session planning #50)

ADR 0027 gives some RulesWarnings a "Go back" choice, which undoes the action with a take-back. Take-backs and TimelineCorrections are #49 and aren't built yet. Until they are, those warnings offer only "Do it anyway", and players take an action back by saying so. "Go back" appears when #49 lands. This amends how ADR 0027 is shown for now, not what it decided.
