# "Not right" on a Shared screen's readback note speaks for the note's player

Status: Accepted (decided with Melissa, 2026-11-28, in the session building #173)

On a Shared screen, "Say what happened…" must speak for a seat (ADR 0107). "Not right" on a readback note (ADR 0137) speaks for the note's player: a spell's or ability's controller; otherwise the player who said the statement the note sits under, which for combat is the attacker; otherwise the active player. This matches "Not right?" on a card, which speaks for that field's player (ADR 0128).

Always speaking as the active player was rejected because a defender correcting a trigger would speak as the attacker. Asking who first was rejected as an extra tap on every correction.
